# Design

Concept: a quiet editorial frame makes native system metrics easy to inspect.
The native application is the focal element; generous paper margins surround
it. Top icon and short chapter title anchor the top edge. One concise English
instruction and chapter progress sit outside application pixels.

Canvas: 1920×1080 tutorial, 1600×960 covers, 960×540 teaser.
Palette: #f8f8fa, #1f2432, #4d7c0f from Top's light theme.
Typography: local Inter variable WOFF2. No native pixel grading, painting,
synthetic pointers, zoom animation or overlay inside the app crop.
